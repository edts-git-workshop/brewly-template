# ☕ Brewly — Launch Kit

**Brewly** is a subscription app that delivers freshly roasted beans from Indonesian
local roasters to your door every month. We are a small product team getting
**Brewly v1.0** ready for launch.

This repository is your team's shared workspace for the Git workshop.
Everything here is plain Markdown — no code. You will edit these documents
the same way an engineering team edits code.

## What's in here

| Path | What it is | Who edits it |
|---|---|---|
| `team/` | One profile file per team member | Each person creates their own (Act 1) |
| `backlog/` | Feature cards for v1.0 | One card per person (Act 2) |
| `product/prd.md` | Product requirements | Your own user story only (Act 3) |
| `product/roadmap.md` | Now / Next / Later | Nobody — you'll practise "undo" on it (Act 3) |
| `product/pricing.md` | Plans and prices | Finance & Sales role cards (Act 4) |
| `release-notes.md` | Launch announcement | Marketing, Engineering & CEO role cards (Act 4) |

## Rules of the game

1. **Only edit what your mission tells you to edit.** The conflicts in this
   workshop are planned — please don't create surprise ones (yet).
2. Step-by-step instructions are in your **handout**, not in this repo.
3. Stuck? Raise your hand — your group helper is here for exactly that.
4. Nothing you do here can break anything permanent. Experiment freely.
